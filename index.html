对局记录

    暗棋象棋 · 规则

    开局

    32 枚棋子（红黑 + 兵种）完全随机落在棋盘的 32 个标准点位上，全部背面朝上。

    • 每个点位同时决定暗子的位置兵种和位置归属。
    • 位置兵种：标准棋局里该位置的兵种，决定它的走法。
    • 位置归属：标准棋局里该位置属于红还是黑。红方阵地上的暗子归红方管，黑方阵地上的归黑方管。

    暗子怎么走（重点）

    • 只能走自己一方的棋子，只能吃对方的棋子：红方走红方阵地上的暗子与己方明子，黑方同理。
    • 暗子先按它所在点位的位置身份行走 / 吃子（兵种走法 + 位置归属），走完自动翻面。
    • 翻面后露出它的真实兵种与真实归属，之后按真实身份行动——可能和刚才的走法、归属都不同。
    • 翻出是对方棋子：它留在落点，归对方所有。
    • 吃暗子也有风险：对方阵地上的暗子翻开后可能是你自己的（含将帅，误吃自家将帅判负）。

    明子走法

    保留基本走法，取消一切地域限制：

    • 車　直线任意格，遇子止步。
    • 馬　走“日”，蹩马腿。
    • 炮　直线走；隔一子吃（暗子也能当炮架）。
    • 相 / 象　走“田”，塞象眼，可以过河。
    • 仕 / 士　斜走一格，可以出九宫。
    • 帥 / 將　直走一格，可以出九宫；双方将帅照面可直接互吃（飞将）。
    • 兵 / 卒　向前一格；过河后可向前后左右任意方向走一格。

    胜负

    • 吃掉对方将帅即获胜。
    • 本玩法不设将军 / 应将：暗子中的将帅无法预警，直接以擒王定胜负。
    • 误吃自家将帅，判负。
    • 无子可走，判负（困毙）。

    操作

    • 悔棋：两侧的“悔棋”按钮，或 Ctrl / Cmd + Z，可连续悔棋。
    • 全屏：菜单 → 全屏；按 Esc 退出。
    • 吃子：被吃的棋子会翻开、放大展示，然后归入吃子方的战利品（与棋子本身是红是黑无关）。

    小提示

    双方阵容固定：每方 2 車、2 馬、2 相/象、2 仕/士、1 帥/將、2 炮、5 兵/卒。暗子带阵营光晕（红 / 黑），按位置身份走；翻面后按真实身份走——“位置”和“真身”的错位就是全部乐趣。
