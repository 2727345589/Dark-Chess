对局记录

    暗棋象棋 · 规则

    开局

    红帅 (4,9)、黑将 (4,0)，以及双方士/仕 (3,9)(5,9) / (3,0)(5,0)，开局即明置并固定在九宫；其余 26 枚棋子（双方各 13 枚）完全随机暗置在其余 26 个点位上。

    • 每个点位同时决定暗子的位置兵种和位置归属：红方阵地上的暗子归红方，黑方阵地上的归黑方。
    • 暗子先按位置身份行走，走完翻面，恢复真实兵种与真实归属。

    暗子怎么走（重点）

    • 只能走自己一方的棋子，只能吃对方的棋子：红方走红方阵地上的暗子与己方明子，黑方同理。
    • 暗子先按它所在点位的位置身份行走 / 吃子（兵种走法 + 位置归属），走完自动翻面。
    • 翻面后露出它的真实兵种与真实归属，之后按真实身份行动——可能和刚才的走法、归属都不同。
    • 翻出是对方棋子：它留在落点，归对方所有。
    • 吃暗子也有风险：对方阵地上的暗子翻开后可能是你自己的（将帅与士除外，它们始终明置）。

    地域限制

    • 帥 / 將、仕 / 士：限九宫（恢复传统限制）。
    • 相 / 象：走田、塞象眼，可以过河。
    • 車 / 馬 / 炮 / 兵卒：保持原走法，取消地域限制。

    明子走法

    • 車　直线任意格，遇子止步。
    • 馬　走“日”，蹩马腿。
    • 炮　直线走；隔一子吃（暗子也能当炮架）。
    • 相 / 象　走“田”，塞象眼，可以过河。
    • 仕 / 士　斜走一格，限九宫。
    • 帥 / 將　直走一格，限九宫；双方将帅照面可直接互吃（飞将）。
    • 兵 / 卒　向前一格；过河后可向前后左右任意方向走一格。

    将军与胜负

    • 恢复将军 / 应将 / 将死：不能把己方走成被将军；被将军必须应将；无解即将死。
    • 暗子按位置身份参与将军判定（位置兵种与归属是公开的）。
    • 被将军时，将帅与正在将军的敌方棋子会高亮。
    • 吃掉对方将帅同样获胜；无子可走且未被将军为困毙，判负。

    操作

    • 悔棋：两侧的“悔棋”按钮，或 Ctrl / Cmd + Z，可连续悔棋。
    • 全屏：菜单 → 全屏；按 Esc 退出。
    • 吃子：被吃的棋子会翻开、放大展示，然后归入吃子方的战利品（与棋子本身是红是黑无关）。

    小提示

    双方阵容固定：每方 2 車、2 馬、2 相/象、2 仕/士、1 帥/將、2 炮、5 兵/卒。将帅与士明置九宫并限九宫；其余暗子带阵营光晕（红 / 黑），按位置身份走，翻面后按真实身份走——“位置”和“真身”的错位就是全部乐趣。
